Pi

Auto clicker with sequences

About the project

One click, or a whole task. The first tab is a classic auto clicker: interval, mouse button, single or double click and a fixed spot or wherever the mouse is. Start and stop with F6.

Sequences. The second tab is a list of steps: click, drag, scroll, key presses, text, waits, loops, wait for a window and run another saved profile as a sub-step. You can also record what you do and edit it afterwards. Long presses become hold steps.

Small random offsets in time and position, a pause key, and it stops by itself if you move the mouse. Before a run it checks the sequence for missing profiles, circular calls and missing pictures, and it warns when the target app runs as administrator. Over 180 automated tests keep it all in place.

Easy to trust. Version 2.3 has an About box that spells out what Pi doesn't do (no internet, no admin rights, nothing in the registry) and shows the program's SHA-256 fingerprint. Everything can be backed up to one file and restored, and a portable mode keeps the settings next to the program. The clicker can put the mouse back after each click or click only while the start key is held, and a sequence can wait for you to press a key before it goes on.

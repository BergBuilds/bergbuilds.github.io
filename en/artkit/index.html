ArtKit

Blender pipeline for game art

ArtKit is BergBuilds' own Blender pipeline: it builds and renders icons, sprites and models with code, so the games and asset packs get consistent art fast.

All projects
StatusIn use
MakesIcons, sprites, 3D models
Built withBlender, Python

About the project

Art as code. Every model is a small Python script that Blender runs without a screen. Lights, camera and materials are shared across a set, so everything fits together.

ArtKit made the art for Pocket Dungeon, Orbit and Glowcap and all 253 icons in the asset packs.

Questions about ArtKit

What is ArtKit?

ArtKit is BergBuilds' own Blender pipeline: it builds and renders icons, sprites and models with code, so the games and asset packs get consistent art fast.

Who made ArtKit?

ArtKit is made by BergBuilds, a small Danish studio on Funen that builds apps, games, asset packs and websites.

What is ArtKit built with?

ArtKit is built with Blender, Python. BergBuilds builds everything in the open with AI as a partner, so tools and code from one project often end up in the next.

Where can I get ArtKit?

In use. Follow the devlog on YouTube or Instagram to hear when it's out.

Can I follow how ArtKit is going?

Yes. BergBuilds shares progress, mistakes and lessons from its projects in short videos on YouTube (@BergBuilds) and Instagram (@bergbuildsdev). New projects show up on the front page as soon as they've started.
